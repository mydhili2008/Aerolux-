# AeroLuxe — Flight Booking Website

A responsive front-end flight-booking website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and animations
- `script.js` — trip tabs, route swap, date validation, demo search, dialog and newsletter interaction

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For development, you can use VS Code with the Live Server extension.

## Important
This is a polished front-end demo, not a live airline booking system. It does not fetch real flight schedules, prices, or availability and does not create reservations. Real bookings require a backend, a trusted flight-search/booking API, secure authentication, payment integration and appropriate data/privacy protections. Destination images and fonts load from external services, so internet access is needed for those assets.
